## System settings

The **Day/Night**, **Settings**, and **Log out** buttons are in the top right corner.

![The top right toolbar](07-settings-toolbar.png)

System Settings shows system and account information and lets you change your password. You can also adjust the display, language, storage, and log storage settings.

![The System Settings panel](07-settings-system.png)

## User roles

To add a user role, click **+ Add Role**, then select the permissions to allow. To change an existing role, use **Edit User Role**.

![The user role permissions](07-user-roles.png)

Use the checkbox beside each camera to set live view and playback permissions.

![Per-camera live view and playback permissions](07-user-roles-cameras.png)

## User accounts

Click **User Accounts**, then **Add User Account**.

![The user accounts list](07-user-accounts.png)

Select a user role, enter the email address, enter the password and confirm it, then create the account.

![Create the user account](07-user-account-create.png)

## Logout

To log out, click **Logout** in the top left corner.

![The logout control](07-logout.png)
